# Bybit Signal Trading Bot

Professional self-hosted algorithmic crypto trading platform for automated Bybit Spot and Futures trading.

The **Bybit Signal Trading Bot** receives signals from TradingView webhooks or the built-in PyDev Signal Engine and automatically executes trades on Bybit with advanced position management, Telegram control and detailed SQLite trading analytics.

## Key Features

- TradingView webhook integration
- Built-in EMA, RSI and MACD Signal Engine
- Automated Bybit Spot BUY execution
- Automated Bybit Futures SHORT execution
- Reverse signal processing
- Take Profit 1 and Take Profit 2
- Partial position closing
- Stop Loss and Break Even
- Trailing Stop management
- Real-time Bybit WebSocket market data
- Telegram control panel and trade reports
- SQLite trading analytics
- Strategy, interval and ROI tracking
- Dry Run, Bybit Testnet and Mainnet modes
- Self-hosted deployment with full source-code control

## Trading Signal Sources

The platform supports multiple signal sources:

- TradingView webhooks
- PyDev Signal Engine
- External API signals
- Manual trade execution

## Trading Analytics

Every completed trade can store:

- Strategy
- Signal source
- Trading engine
- Timeframe
- Entry and exit price
- Trading fees
- Funding fees
- Gross and net profit
- ROI
- Holding time
- Close reason

The analytics module provides daily, weekly, monthly and all-time trading statistics.
